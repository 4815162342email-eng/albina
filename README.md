# Принцесса Альбина

Браузерная игра, которую придумала и нарисовала юная художница семи лет.

Принцесса Альбина живёт в замке на горе. Злой волшебник Рарин унёс её маленького брата Мирина в свою пещеру. Альбина варит зелья, чинит мост под дождём, переходит болото по кувшинкам, расколдовывает волка и в волшебной дуэли спасает брата. А на помощь ей по хлопку в ладоши приходит одноклассник Эрен.

## Как играть

Откройте `index.html` в браузере (Chrome, Edge, Firefox) или ссылку GitHub Pages этого репозитория. Управление мышкой. Прогресс сохраняется в браузере.

Вся игра — один файл `index.html`, без установки и без сервера.
